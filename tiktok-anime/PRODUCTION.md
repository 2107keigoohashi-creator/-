# 毎日の制作ガイド

1日1本。物語は **前編 → 後編** の2本で1話。毎朝（カナダ太平洋時間 7:52）、作る内容をオーナーに確認し、**承認されてから** 作る。
進み具合は `SERIES.md` に記録する。

## 毎朝の流れ

1. `SERIES.md` を読み、今日作る回を決める
   - 直近の物語の **前編だけ** できている → 今日はその **後編**
   - それ以外 → **新しい物語の前編**（前編・後編の2本分のあらすじを一緒に提案する）
2. オーナーに提案して、返事を待つ（**承認されるまで作り始めない**）。提案に入れるもの:
   - タイトル（前編/後編）
   - あらすじ（3〜5行）と結末（後編）／引き（前編）
   - 主な見せ場のシーン（5〜8個の箇条書き）
   - 新しく作る背景・キャラ・小物があればその一覧
3. 承認されたら、下の「作り方」で制作 → mp4 を送る → `SERIES.md` を更新 → コミット・プッシュ
4. 修正の指示があれば直して、もう一度送る

## 作り方

```bash
cd tiktok-anime
npm install                      # コンテナが新しいときだけ
npm run voicevox                 # Docker と VOICEVOX を起動（429 は自動で再試行）
# episodes/ep02-1.json を書く（ID は英小文字・数字・ハイフンのみ。ep02-1 = 第2話 前編、ep02-2 = 後編）
npm run kana -- ep02-1           # 読み間違いを確認 → 必要なら reading で直す
npm run voice -- ep02-1          # 音声＋字幕タイミング
npm run still -- ep02-1 1 5 10 15 20 25   # 静止画で確認（重なり・はみ出し）
npm run render -- ep02-1         # out/ep02-1.mp4
cp out/ep02-1.mp4 ../output/tiktok_anime_ep02-1.mp4
```

## 台本の決まり

### カット多め
- **1シーン = 1〜2文、3〜6秒**。長くなりそうなら、シーンを分ける。
- 1本あたり **25〜40シーン**、全体で **90〜150秒** を目安に。
- 4秒を超えるシーンには `cuts` を入れて、引き → アップ（顔・手・計器）を切り替える。
  ```json
  "cuts": [{ "at": 2.5, "zoom": 1.7, "focusX": 780, "focusY": 900 }]
  ```
- 同じ背景が続くときは、画角（`camera` / `cuts`）・キャラの向きや表情を毎回変える。

### 字幕多め
- ナレーション字幕は自動で出る（読み上げに合わせて切り替わる）。字幕1枚は20文字以内が目安なので、**文は短く、読点「、」で区切る**。
- 大きなテロップ（`telop`）は **全シーンに** 入れる。要点を【】で赤くする。
- セリフは `bubble`（吹き出し）でも見せる。

### ナレーションを自然に
- 書き言葉ではなく **話し言葉** で。「〜である」より「〜なんだ」「〜だ」。
- 1文は短く（30文字前後まで）。体言止め・問いかけを混ぜる。
- 「・」入りのカタカナ（ツー・コミュニケーション）や「……」は、自動で読み上げ用に整える（`shared/text.mjs`）。
- `npm run kana` で読みを全部確認し、おかしい語は `reading` で直す（例：操縦桿 → 操縦かん）。
- 声の設定は `episodes/voices.json`。登場人物ごとに声を分けたいときは、プリセットを足してシーンの `voice` で指定する。

### 物語形式
- 主人公の視点で進める（ep01 の「あなた」など）。最初の3秒で「何が起きるか」を見せる。
- 前編は **引き**（次が気になる場面）で終える。最後のシーンのテロップは「後編につづく」。
- 後編の冒頭2〜3シーンは前編のおさらい。最後に学び（まとめ）を入れる。
- 航空・医療などの事実は、正確さを確認する。不確かなことは断定しない。

## 品質チェック（送る前に）

- 静止画で、テロップ・字幕・吹き出しが顔や見せ場に重なっていないか
- `npm run kana` で読み間違いがないか
- mp4 の音量（`ffmpeg -i out/xx.mp4 -af ebur128 -f null -` で -14〜-16 LUFS 前後）
- 投稿用クレジット：VOICEVOX:青山龍星（ほかの声を使ったらそれも）
